# Social post buffer — 4 weeks of ready-to-ship posts

Eight fully drafted posts. Two per week × four weeks = one month of rhythm. Pick the order that suits the photos you have on the day. Don't over-schedule; the point is to remove the "what do I post" friction, not lock you into a calendar.

Caption length is tuned for Instagram (the harder constraint); all of these work for Facebook unchanged. Hashtags are listed separately so you can omit on Facebook.

**Cross-posting note:** If your Instagram and Facebook are linked (Meta Business Suite), turn on "share to Facebook" when posting on IG. That mirrors automatically and you only think about it once. Don't manually re-author on Facebook — duplicate effort.

## Posting cadence reminder (from playbook.md)

- **2 posts per week is the sustainable target.**
- **Best times (NZ):** Tuesday or Thursday, 7–9pm NZT.
- **First-hour reply discipline:** reply to every comment within 60 minutes. Single biggest algorithmic lever.
- **Don't cross-post manually.** Use Meta's auto-share from IG → FB.

## How to use this buffer

1. Pick whichever post the photo you have on the day matches. Don't post in numerical order if the matching photo isn't ready.
2. Tweak the caption to feel like *you* — never paste verbatim if a word reads off. The drafts are 90%-there; the last 10% is your voice.
3. Strike through (or delete) each post in this file after you ship it, with the date. That way the file is also a log.
4. When the buffer's depleted, I can spin up the next 8. Just say "more posts."
